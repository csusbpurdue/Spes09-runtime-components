# Runtime Components

This repository contains my personal runtime component configuration files for Linux and development tools.

## Files

* `.bashrc` - Configuration for the Bash shell.
* `.zshrc` - Configuration for the Zsh shell.
* `.vimrc` - Configuration for Vim.
* `.gitconfig` - Configuration for Git.
* `.gdbinit` - Configuration for GDB.
* `install.sh` - Script for installing the runtime components in their appropriate locations.

## Installation

Clone this repository and run the installation script:

```bash
git clone git@github.com:Spes09/runtime-components.git
cd runtime-components
chmod +x install.sh
./install.sh
```

The installation script copies the runtime component files to their appropriate locations.

## Purpose

The purpose of this repository is to keep my development environment configurations in one place so they can be easily reused on another computer or server.
